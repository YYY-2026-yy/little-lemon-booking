# Little Lemon Restaurant Booking Web App
This is the capstone project for Meta Front-End Developer Certificate.
A table reservation website for Little Lemon restaurant, built with React.

## Features
- Table booking form with form validation
- Date, time, guest number selection
- Responsive layout for mobile & desktop
- Accessibility support (alt text, label, semantic tags)
- Error handling for edge cases
- Unit tests with Jest

## Tech Stack
- React
- JavaScript
- CSS
- Jest
